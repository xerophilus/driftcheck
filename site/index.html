How does the license work?

What frameworks are supported?

Any Node/TypeScript project. Works with Next.js, Vite, Express, Remix, etc. Also scans Python and Go code for env vars.

Do I need to connect my providers?

No. The tool works without provider access (static checks only). For live provider checks, supply tokens via env vars. Your tokens never leave your machine.
